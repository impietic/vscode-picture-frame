# Picture Frame
![A view of the extension, inside the Explorer area and underneath the Outline and Timeline section is the Picture Frame extension showing a picture of a man sitting in a reclined chair under the sunset](https://raw.githubusercontent.com/impietic/vscode-picture-frame/main/assets/ss.png)

This extension displays a picture in a VS Code side panel view. By default it sits in the Explorer sidebar, underneath Outline and Timeline, but you can drag its tab wherever you like, same as any other view. That's all it has, nothing else.

I built this just to set a picture of my girlfriend in my panel and there's no other extensions for that, which I find weird since I'm sure others have thought about it, but here we are.
